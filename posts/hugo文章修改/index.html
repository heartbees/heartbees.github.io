Hugo文章修改

用 VS Code 可视化修改已发布的 Hugo 文章，无需命令行，修改后一键同步到线上
February 4, 2026 · 1 min · 147 words · 小香猪

考虑安装辅助插件： GitLens： 代码行末显示最后修改信息，方便追踪历史 Markdown All in One： 提供更强大的 Markdown 编辑支持 Front Matter： 方便管理 Hugo 文章的 YAML 头部信息 养成良好习惯： 定期备份本地仓库（或直接使用 GitHub 作为主要备份） 小幅度、频繁提交，而非一次性大量修改 推送前先在本地预览（hugo server -D），确保内容无误
